## 📖 Sobre este repositório

Este espaço é dedicado à documentação das minhas resoluções em laboratórios de segurança. Aqui, registro o passo a passo da prática de *penetration testing* e análise de vulnerabilidades, operando principalmente em ambientes da TryHackMe através de conexão VPN.

O objetivo principal deste portfólio é documentar a *kill chain* completa dos ataques para consolidar os conhecimentos táticos necessários. Essa vivência prática utilizando o Metasploit Framework e outras ferramentas de exploração reforça a visão analítica essencial para atuar de forma remota em um Security Operations Center (SOC). O entendimento profundo da perspectiva do atacante é a chave para construir defesas mais robustas, inclusive em arquiteturas modernas de cloud security.
