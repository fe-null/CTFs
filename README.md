## 📖 Sobre este Quartel-General (QG)

Bem-vindo ao meu repositório central de Cibersegurança. Este espaço foi desenhado para consolidar os meus relatórios técnicos (**Writeups**) e metodologias de ataque/defesa aplicadas em ambientes de simulação realistas. 

O objetivo primário deste portefólio é documentar a evolução contínua das minhas competências analíticas e operacionais direcionadas para **Security Operations Center (SOC)** e **Penetration Testing**. Aqui, cada CTF é tratado como uma investigação forense e um teste de intrusão rigoroso, detalhando a **Kill Chain** desde a fase de reconhecimento até à exfiltração de dados e escalonamento de privilégios.
